# Security Policy

## Scope

This repository contains offline, sanitized lab examples. It is not a production automation platform and does not require credentials.

## Reporting a concern

Please open a private security advisory through GitHub rather than publishing credentials, private configurations, internal addresses, or customer information in a public issue.

## Safe-use rules

- Never commit passwords, API tokens, SSH keys, SNMP communities, or private certificates.
- Never copy employer or customer configuration into this public repository.
- Use documentation address ranges and fictional device names in examples.
- Review generated configuration and test it in an isolated lab before considering any production use.
- Use normal change control, peer review, validation, and rollback procedures.
